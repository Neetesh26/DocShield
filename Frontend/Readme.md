# DocuShield Frontend Client
> Enterprise React + Vite Single-Page Application for GxP Document & Physical Warehouse Archive Governance.

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Production build
npm run build
```

The frontend runs on port `5173` and proxies API requests to `http://localhost:5000`.
